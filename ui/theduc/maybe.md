Cấu trúc:
 app/component: folder lưu code các màn hình tính năng
 app/domain: khai báo các file ts mapping kết quả api
 app/mock: dữ liệu nội dung giao diện ví dụ menu
 app/type: constant, final, enum
 app/utils: hàm dùng chung
 app/api: file khai báo các api
 app/config: khai báo cấu hình ví dụ axios
